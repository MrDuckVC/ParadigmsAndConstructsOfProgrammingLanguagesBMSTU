# BackupSync

**BackupSync** — это высокопроизводительное Windows-приложение для интеллектуальной синхронизации и резервного копирования данных между локальной файловой системой и внешними USB-носителями. 

Проект ориентирован на обеспечение сохранности данных при работе со сменными устройствами, предлагая расширенные алгоритмы анализа изменений и разрешения конфликтов.

## 🚀 Ключевые возможности

* **Аппаратная привязка (Hardware Awareness):** Автоматическое обнаружение устройств через WMI. Идентификация происходит по уникальному серийному номеру тома (VSN), что исключает ошибки при смене букв дисков в Windows.
* **Трехэтапный движок синхронизации:**
    1.  **Анализ:** Глубокое сканирование и сравнение метаданных файлов.
    2.  **Политики:** Применение предустановленных правил (One-Way / Two-Way).
    3.  **Исполнение:** Безопасное выполнение файловых операций с обработкой исключений.
* **Интеллектуальное разрешение конфликтов:** Система выявляет ситуации, когда файлы были изменены одновременно на обоих носителях, и предоставляет пользователю удобный интерфейс для выбора версий.
* **Управление устройствами:** Возможность "забывать" старые носители или перепривязывать существующие профили к новым дискам после форматирования.

## 🛠 Технологический стек

* **Runtime:** .NET 8.0 / C# 12
* **UI Framework:** WinUI 3 (Windows App SDK) — современный нативный интерфейс в стиле Fluent Design.
* **Database:** Entity Framework Core + SQLite для надежного хранения конфигураций и истории устройств.
* **Pattern:** MVVM (Model-View-ViewModel) с использованием CommunityToolkit.Mvvm для чистого разделения логики и представления.
* **System:** Windows Management Instrumentation (WMI) для низкоуровневого мониторинга состояния системы.

## 🏗 Архитектура проекта

Проект разделен на два основных слоя:
1.  **BackupSync.Core:** Библиотека классов, содержащая бизнес-логику, модели данных, контекст БД и сервисы синхронизации. Не зависит от UI.
2.  **BackupSync.UI:** Слой представления, включающий в себя XAML-описания страниц, диалогов и соответствующие ViewModels.

## ⚙️ Установка и развертывание

### Требования
* Windows 10 версии 1809 (17763) или новее.
* Visual Studio 2022 с установленной нагрузкой "Разработка классических приложений для .NET".

### Запуск
1. Клонируйте репозиторий:
    ```bash
    git clone [https://github.com/your-username/BackupSync.git](https://github.com/your-username/BackupSync.git)
    ```
2. Откройте файл решения `BackupSync.sln`.
3. Выполните инициализацию базы данных в Package Manager Console:
    ```powershell
    Update-Database -StartupProject BackupSync.UI
    ```
4. Запустите проект `BackupSync.UI (Package)`.
